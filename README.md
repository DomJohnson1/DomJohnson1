# Huntley Homework Hero
Huntley Homework Hero is a web app where students can anonomously post homework questions and teachers can respond.

## Features
- Login Page
- Post Questions
- See other posted questions
- Profile Page
- View response to questions
- Insert files with posted questions


## Technologies
- Python(Flask)
- HTML/CSS/JavaScript
- JSON
- Python Image Library(PIL)
